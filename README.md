# Out-Of-Home Purchase Behavior Analysis

This project analyzes the out-of-home purchase behaviors of 3,338 French households. The analysis uses sociodemographic criteria for data adjustment, including the household head's occupation, age, household size, residential region, and urban category.

## Project Structure

### Part 1: Survey Extrapolation and Data Processing

1. Introduction: Overview of the sampling process, data adjustment, and extrapolation.
2. Survey Extrapolation: Uses sociodemographic criteria (CSPCHEF, AGECHEF, REGION, NBPERS, TU) to estimate survey results for the entire population.
3. Survey Data Processing: Conducts univariate and bivariate analyses using cross-tabulation and flat tables.
4. Significance Testing: Measures the association between responses and sociodemographic criteria.

### Part 2: Multivariate Analysis

5. Multivariate Characteristics: Uses the CHAID algorithm and decision trees to explore multivariate characteristics of response modalities.
